# Японский в кармане

Разговорник для поездки в Японию: 12 ситуаций, ~160 фраз, ~320 слов, озвучка, конструктор фраз и карточки. Работает без интернета и ставится на телефон как приложение. Первый «языковой пакет» будущего многоязычного приложения.

## Структура

| Папка / файл | Что внутри |
|---|---|
| `docs/` | **Сам сайт** — именно его публикует GitHub Pages. |
| `docs/index.html`, `app.css`, `app.js` | Движок: интерфейс, поиск, карточки, конструктор. Не зависит от языка. |
| `docs/packs/ja.js` | Японский пакет: ситуации, фразы, слова, иллюстрации, правила чтения. |
| `docs/packs/ja-audio.js` | Соответствие «текст → аудиофайл» (генерируется). |
| `docs/audio/ja/*.mp3` | Озвучка (синтезированный голос). |
| `docs/sw.js`, `manifest.json`, `icons/` | Работа без интернета и установка как приложения. |
| `tools/` | Скрипты озвучки. В сайт не входят. |
| `archive/` | Первая версия-страница с claude.ai, для истории. |

## Публикация на GitHub Pages

1. **GitHub Desktop → File → Add local repository…** → выберите эту папку (`japan-travel`).
2. Появится сообщение, что это ещё не репозиторий, — нажмите **create a repository** → **Create repository**.
3. Нажмите **Publish repository**, **снимите галочку «Keep this code private»** → **Publish repository**.
4. На github.com откройте репозиторий → **Settings → Pages** → *Source:* `Deploy from a branch`, *Branch:* `main`, папка **`/docs`** → **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/japan-travel/`.

Обновление: меняете файлы → в GitHub Desktop **Commit to main → Push origin**. Установленное приложение подхватит новую версию со второго запуска с интернетом.

## Установка на телефон

- **Android (Chrome):** кнопка «Установить как приложение» на главной (или меню ⋮ → «Установить приложение»).
- **iPhone (Safari):** «Поделиться» → «На экран Домой».

При первом открытии приложение само сохраняет всё нужное, включая озвучку (~8 МБ). Статус — в разделе «あ».

## Как перегенерировать озвучку

Нужны Node.js и Python с пакетом `edge-tts` (`pip install edge-tts`).

```
node tools/build-audio-list.js ja
python tools/tts.py ja ja-JP-NanamiNeural
```

Первый скрипт собирает все тексты пакета, второй озвучивает только новые и удаляет лишние файлы. Озвучка через сервис Microsoft Edge подходит для личного проекта; для платного приложения лучше переозвучить сервисом с коммерческой лицензией.

## Новый язык

Создайте `docs/packs/<код>.js` по образцу `ja.js`, добавьте код языка в `PACKS` в `docs/sw.js` и сгенерируйте озвучку теми же скриптами.
